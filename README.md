# IELTS 每日練習

給 James 的靜態練習站。全部介面是繁體中文，進度、錯題和匯入的文件只存在這台裝置。

- **今日練習**：每天 10 題，錯題優先，再依單元順序學新字。
- **題庫**：自由練習。可選字彙主題、文法重點、閱讀、聽力（語音播放）、寫作片語、口說題卡，長度 10／20／全部。
- **閱讀器**：內建六篇文章，也可匯入 PDF、docx、txt、md 或貼上文字。點字可聽發音、看中文（有收錄時）並收藏。
- **單字本**與**進度**：錯題、收藏、連續天數、考試倒數（預設 2027-06-07）。

加入主畫面後可離線使用。掃描而成、沒有文字層的 PDF 無法辨識。聽力用瀏覽器語音，不是真人錄音。Chrome 的語音辨識由瀏覽器提供，網站本身不會把答案上傳。
